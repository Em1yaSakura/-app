# EnglishAPP - 英语单词学习 App

基于 Android Jetpack Compose 的英语单词学习 App，内置 SM-2 + 艾宾浩斯记忆算法，支持考研、四六级词汇学习。

## 功能

- 🎯 **SM-2 + 艾宾浩斯记忆算法** - 科学安排复习
- 🆕 **三种学习模式** - 新单词 / 复习 / 混合
- 🔊 **有道 TTS 发音** - 学习时自动发音
- 📊 **学习统计** - 学习趋势、连续天数、记忆阶段
- ⏱ **计时功能** - 记录每个单词的学习时间
- 📖 **在线增强释义** - 翻转卡片后查询详细的单词释义
- 📚 **多词书支持** - 考研英语、CET-4、CET-6

## 词书来源

本 App 中的词汇数据来源于 [maimemo-v3.4](https://github.com/Dr-Quan/maimemo-v3.4)，该项目导出了墨墨背单词 V3.4 版本的词典数据，仅供个人学习使用，**禁止用于商业用途**。

## 技术栈

- **语言**: Kotlin
- **UI**: Jetpack Compose (Material3)
- **数据库**: SQLite (SQLiteOpenHelper)
- **构建工具**: Gradle
